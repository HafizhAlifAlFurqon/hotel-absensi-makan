Cara 1: Buka di Figma Canvas (Rekomendasi)

  1. Klik tombol "Salin SVG (Paste ke Figma)" di atas.
  2. Buka project / file baru di aplikasi atau web Figma.
  3. Tekan Ctrl + V (atau Cmd + V di Mac).
  4. Diagram akan langsung ter-paste sebagai Vector Frame & Layer Figma asli (bisa diganti warna, font, dan di-edit setiap teksnya). Atau cukup drag file diagram-flow-absensi.svg langsung ke dalam lembar kerja Figma!

Cara 2: Buka di FigJam (Menggunakan Mermaid)

  1. Klik tombol "Salin Kode Mermaid" di atas.
  2. Buka papan FigJam Anda.
  3. Buka menu Widget / Plugins (Ctrl + /), cari "Mermaid".
  4. Paste kodenya, dan diagram flowchart akan langsung digambar otomatis menjadi diagram FigJam interaktif!
