Panduan Lengkap Publikasi Hosting & cPanel

Langkah demi langkah memindahkan website absensi makan ke domain cPanel aktif.

Langkah 0: Siapkan File Database SQL

Unduh file database MySQL terkompresi yang siap di-import langsung ke phpMyAdmin hosting.

1
Buat Database & Pengguna di cPanel

Login ke cPanel hosting Anda → Masuk ke menu MySQL Databases → Buat database baru (contoh: user_absen) → Buat user database baru beserta password kuatnya → Tambahkan user ke database tersebut dan centang ALL PRIVILEGES.

2
Import Database di phpMyAdmin

Buka menu phpMyAdmin di cPanel → Klik nama database Anda di panel kiri → Buka tab Import → Pilih file absen_makan_hotel_backup_....sql yang baru diunduh → Klik tombol Kirim (Go) di bawah. Semua tabel akan terbuat otomatis!

3
Upload File Proyek ke File Manager (public_html)

Buka menu File Manager di cPanel → Masuk ke folder public_html (atau subdomain yang Anda tuju) → Upload file proyek.

File Wajib Di-Upload:
index.html, api.php, config.php, .htaccess, folder css/, folder js/
Tidak Perlu Di-Upload:
node_modules, .git, database.sql mentah, file backup lama, installer XAMPP.
4
Sesuaikan File Konfigurasi (config.php)

Klik kanan file config.php di File Manager cPanel → Pilih Edit → Isi nama DB, User, dan Password sesuai yang dibuat di Langkah 1:

define('DB_HOST', 'localhost');
define('DB_NAME', 'usernamecpanel_namadb');
define('DB_USER', 'usernamecpanel_userdb');
define('DB_PASS', 'PasswordHostingAnda');
define('DB_PORT', '3306');
5
PENTING: Aktifkan SSL / HTTPS (Let's Encrypt / AutoSSL)

Kamera scanner smartphone (Chrome, Safari, iOS, Android) WAJIB menggunakan HTTPS.
Di cPanel, cari menu SSL/TLS Status → Centang domain Anda → Klik tombol Run AutoSSL. Tunggu 2-5 menit hingga ikon gembok hijau aktif. Sistem akan otomatis aman dan kamera dapat diakses seketika!

6
Uji Coba Live & Ganti Password Admin Default

Buka website lewat domain Anda (misal: https://absen.bessmansionhotel.com). Login sebagai admin, pastikan database tersinkronisasi, dan ganti password admin default (admin123) ke password baru demi keamanan properti hotel.
